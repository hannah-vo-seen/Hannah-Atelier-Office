# Hannah Atelier Office

Trang tĩnh hiển thị trạng thái các agent trong một thành phố 3D (Three.js, đã đi kèm trong `vendor/`).

Chạy thử trên máy: `python3 -m http.server 8000` rồi mở http://localhost:8000

Sửa `agents.json` để đổi trạng thái (ready, waiting, idle, off, planned) và phòng ban (`sub`).

Không đưa token, file .env hay số liệu quảng cáo vào repo này.
